# Security policy

## Reporting a vulnerability

Report security problems privately by email to **security@ordevra.com**.

**Do not open a public issue, pull request or discussion** for a security problem,
and do not include exploit details, credentials or personal data anywhere public.

Please include what you found, where, how to reproduce it and what an attacker
could do with it. We will acknowledge the report and keep you informed while we
investigate.

If you find a secret or credential committed to a repository, report it the same
way. Do not copy it anywhere else.
