

# Contributor instructions

> Purpose: Guide contributors to the repository's shared operating context.

## Repository documentation procedure

Read the shared repository context before editing: [requirements](docs/repository/requirements.md) | [decisions](docs/repository/decisions.md) | [known-issues](docs/repository/known-issues.md) | [progress](docs/repository/progress.md). Update affected authorities in the same PR, or explain no documentation impact in its description. Keep one canonical set; do not add personal copies or mirror a task board. Preserve decision history and distinguish implemented, tested and deployed. The PR author owns the assessment; reviewers verify its accuracy.

Follow [CONTRIBUTING.md](CONTRIBUTING.md). Keep all content public-safe; private organization context does not belong here.
